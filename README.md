# Semble.CC

**Convene With Confidence.** The app to physically build in public.

Live: [semble.cc](https://www.semble.cc)

- `/` — Semble
- `/init` — the word
- `/app` — the app
- `/cc` — Semble CCs · Community Cores. Live voice rooms.
- `/spec` — the open baseline spec ([SEMBLE-SPEC.md](SEMBLE-SPEC.md))

Static site. No build step. No backend — CCs run peer-to-peer over WebRTC.
